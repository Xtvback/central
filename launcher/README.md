# Central Launcher — Windows

## Instalação noutros computadores

1. Transferir o ficheiro `CentralLauncher_Setup_1.0.0.exe` para o computador Windows.
2. Executar o instalador e seguir as instruções (Português).
3. Abrir a aplicação pelo menu Iniciar ou através do ícone no Ambiente de Trabalho, se selecionado.
4. Os **links online** funcionam em qualquer computador ligado à Internet.
5. Para os projetos **locais**, carregar em **Configurar** e indicar onde está o ficheiro do jogo ou a pasta nesse computador. Instalar um launcher **não instala os jogos**, nem transfere os seus ficheiros.

## Funcionalidades da versão 1.0.0

- Aplicação gráfica Windows, não dependente de Python instalado no computador de destino.
- 17 cartões iniciais para jogos USLORDS, música Solvero, escrita, podcasts, redes sociais, GitHub e APEE.
- Pesquisa e filtros por categoria.
- Botões para abrir ficheiros e projetos locais ou páginas online.
- Possibilidade de criar, editar e remover cartões sem alterar os projetos.
- Configurações locais independentes por computador, guardadas em `%APPDATA%\\CentralLauncher\\projects.json`.
- Inno Setup per-user: instalação no perfil do Windows, sem requerer direitos de administrador.

## Informação importante

A lista inicial reproduz e complementa o repositório público `https://github.com/Xtvback/central`. A aplicação de Windows é um projeto **separado**: não modifica automaticamente o website público ou o repositório original. As alterações à lista são guardadas **só no computador onde forem feitas**. O launcher não sincroniza automaticamente as configurações entre computadores nesta versão.

## Origem do código

Código-fonte e ficheiros de construção: pasta `Documents\\Central_Launcher` no PC principal. O instalador na Google Drive pode ser copiado e instalado noutros PCs Windows x64.

## Segurança

O instalador não inclui passwords nem acesso às contas. Abrir Suno, DistroKid ou Google Drive pode exigir login em cada computador. Não desativa antivírus nem a proteção do Windows.
